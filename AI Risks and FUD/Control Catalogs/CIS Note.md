# CIS Controls: Version Used and Where to Get It

This research uses the CIS Critical Security Controls, but this repository does not include the CIS safeguard catalog. The CIS Controls are licensed under [Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International](https://creativecommons.org/licenses/by-nc-nd/4.0/legalcode), which limits how they can be shared and does not allow distributing modified versions. The catalog used in this research restructures the safeguard text, so it is not published here.

## Version used

*CIS Critical Security Controls Version 8.1*, document version 8.1.2 (March 2025), published by the Center for Internet Security, Inc. It contains 18 Controls and 153 Safeguards.

## How to follow the citations

Notes in this repository cite safeguards by number, such as `CIS: 6.8`. To read a safeguard's text, look up its number in the CIS document:

- [CIS Critical Security Controls v8.1: version description and download](https://www.cisecurity.org/insights/white-papers/cis-critical-security-controls-v8-1)
- [CIS Controls: current version](https://www.cisecurity.org/controls/)

Links to `CIS Controls v8.1 Catalog` in these notes point to the unpublished catalog and will not open. Use the CIS document instead.
